# خطة تطوير موقع Portfolio — إصلاح + تلميع احترافي + شهادات جديدة + نشر

**الوضع الحالي:** موقع ثابت (HTML/CSS/JS بدون build) ثنائي اللغة EN/AR مع 5 ثيمات، PWA، مساعد ذكي، 9 شهادات، منشور على Vercel.

---

## المرحلة 0: التهيئة والأدوات
1. تشغيل `npx skills add https://github.com/vercel-labs/skills --skill find-skills` لاكتشاف مهارات مفيدة إضافية.
2. تحميل مهارة `landing-page-design` لتوجيه تحسين الـ Hero وصفحة الهبوط.
3. **سؤالك عن مسار مجلد الشهادات الجديدة** (أنت قلت ستعطيني المسار لاحقاً — سأطلبه أول التنفيذ).
4. تشغيل خادم محلي للمعاينة والاختبار.

## المرحلة 1: إصلاح جميع الأخطاء المكتشفة (17 مشكلة)

**حرجة:**
1. **توحيد النطاق** إلى `https://abdullah-portfolio26.vercel.app/` (النطاق الآخر `abdullah-profile` يخص شخصاً آخر!): `script.js:2867,2940` (روابط Live Site في case-study)، `sitemap.xml`، `robots.txt`، `README.md`
2. **إصلاح تبديل اللغة** (`script.js:624`): مصفوفة `langTeardowns` تُستهلك بعد أول تبديل — سأحوّلها لنظام أحداث persistent (`languagechange`) بحيث يتحدث رسم المهارات الراداري وشرائح المساعد الذكي وإلغاء الصوت عند كل تبديل لغة
3. **حذف كود المدونة الميت**: `setupArticleModal()` + `ARTICLES` + مفاتيح `blog.*` في `script.js`، و~110 سطر CSS في `styles.css:4171-4284`

**متوسطة:**
4. عدّاد الإحصائيات يتجمد عند إخفاء التبويب — ربط `resume` بحدث `visibilitychange` (`script.js:1681`)
5. نقاط التنقل بالعربية تعرض "home/experience/feedback" — إضافة مفاتيح `nav.home/experience/feedback` للقاموسين
6. تعريضات favicon متضاربة — توحيدها وإزالة عنصر text فارغ
7. تحية المساعد الذكي العربية (مساء/مساء مكررة) `script.js:2153`
8. خصوصية ذاكرة المساعد: تطبيق `redact()` قبل الحفظ وليس عند العرض فقط
9. إصلاح أزرار متداخلة في الـ timeline (a11y) + إزالة `window.handleSubmit` الشامل

## المرحلة 2: الأداء

- ضغط الأيقونات (icon-512: 202KB → ~25KB)

- تحديث `sw.js` (ترقية الكاش v4→v5 + إضافة 404.html للـ CORE)

## المرحلة 3: التلميع الاحترافي الشامل (الجمالية)
- **Hero أقوى**: تسلسل عنواني أفضل، CTA أوضح، عناصر عائمة مصقولة، توهجات أدق
- **بطاقات أنعم**: hover بحدود مضيئة + رفع خفيف، اتساق الظلال والزوايا
- **قسم الشهادات**: عرض أفخم مع تأثير zoom وشارة عدّاد محدثة
- **إيقاع أقسام موحد**: eyebrows وعناوين وتباعد متسق عبر كل الأقسام
- **تحسين الخطوط**: ترقية مقاسات وتباعد الأسطر + فحص عرض العربية
- **التحقق من الثيمات الخمسة كلها** بصرياً واحداً واحداً
- تحسين التركيبة وفق مبادئ مهارة landing-page-design (F-pattern، تباين CTA، social proof)

## المرحلة 4: رفع الشهادات الجديدة
- نسخ الصور إلى `assets/certs/` بأسماء نظيفة (kebab-case) + ضغطها (+ تحويل PDF→صورة إذا لزم عبر مهارة pdf)
- إضافة بطاقات HTML + ترجمة EN/AR + `CERT_INDEX` + أيقونة لكل جهة
- تحديث عدّاد "9+ Certifications" في الإحصائيات + معرفة المساعد الذكي (script.js + api/chat.js) + README

## المرحلة 5: التحقق من خلوه من الأخطاء
- `node --check` على كل ملفات JS + فحص HTML واتساق مفاتيح i18n
- **اختبار بالمتصفح الفعلي** (مهارات browser-use/web-gui-tester): تبديل اللغة مرتين، الثيمات الخمسة، Lightbox للشهادات الجديدة، القائمة على الجوال، العدّادات، النوافذ المنبثقة، المساعد الذكي — مع لقطات شاشة
- فحص قبول بصري (judge) على الصفحات المصيّرة

## المرحلة 6: النشر على Vercel
- نشر الإنتاج عبر Vercel CLI (مهارة vercel-cli-with-tokens) ثم التحقق من الموقع الحي وsitemap
