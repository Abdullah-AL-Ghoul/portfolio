References inspected with a real headless Chromium browser via Playwright 1.63 (viewport 1440x900 desktop full-page + 390x844 mobile full-page screenshots; everything below was extracted through DOM queries — `page.evaluate` for computed styles, selectors, CSS custom properties, and `innerText`). Screenshots are saved as evidence in `gui-test-screenshots/v3-research/` (figma/framer/webflow/raycast/supabase `-desktop.png` + `-mobile.png` plus per-site `-analysis.json`). No reference bot-walled the headless browser; all five rendered real content. Target context: Abdullah's bilingual (EN/AR, RTL) developer portfolio, brand "Dark Precision Engineering", 5 themes, no fabricated metrics.

## Cross-reference patterns (strongest, transferable)

1. **One H1, one primary message, one dominant CTA.** Every site leads with a single big H1 + small subhead + exactly one primary button (Figma: "Get started" black; Webflow: "Get started" blue; Supabase: "Start your project" green; Framer/Raycast: white "Get started"/"Download"). No hero clutter.
2. **Dark canvas + white primary CTA + translucent secondary.** Framer and Raycast prove a dark hero (`#000` / `#07080a`) with a light primary button and a `rgba(255,255,255,0.1)` secondary is the "engineering" look — directly maps to our default dark theme and brand.
3. **Design tokens, not per-page values.** Figma (type/space props), Raycast (8px scale + rounding), Webflow (clamp()) all centralize type, spacing, color, radius. This is what will keep 5 themes + RTL consistent.
4. **Real product surface in situ beats description.** Framer (~90 product-window images) and Raycast (full-size `RaycastWindow` replicas) render their actual UI as the hero/feature visual.
5. **Benefit + evidence cards.** Webflow pairs every benefit with a big real metric and "Read story →"; Supabase puts live "111.2K" stars in the nav. Apply only with *real* numbers (we cannot fabricate).
6. **Capability cards as a grid unit.** Figma and Supabase both use icon + title + one-line desc (+ micro-bullets) cards in 2–4 col grids that collapse to 1 col.
7. **H2s as brand statements.** Framer/Supabase write section headers as confident POVs ("Not just vibes, a full platform", "Build in a weekend / Scale to millions") rather than feature labels — fits "Dark Precision Engineering" voice.
8. **Fluid clamp() rhythm.** Webflow's `clamp()`-driven display type keeps proportionality mobile→desktop, which we should mirror with logical-property-safe clamps.

## Method & fidelity notes
- Command run per reference: `node .agents/research-inspect.mjs <url> <name>` (Playwright 1.63, headless Chromium). This is the exact tool that produced the observations above; raw extracted JSON is in `gui-test-screenshots/v3-research/<name>-analysis.json`.
- All 5 references were observed via real rendered DOM + screenshots saved as evidence files. No WebFetch fallback was needed (none bot-walled). Raycast's desktop full-page screenshot needed a retry with a 90s screenshot timeout after the default timed out; its DOM analysis succeeded on first pass.
- Supabase CTA colors were captured with a second targeted pass (`node .agents/cts.mjs`) because the primary button fills are on child elements; all other data came from the single inspect pass.
- Metrics like "95% of Fortune 500", "$200M pipeline", "67% dev ticketing" are **Figma/Webflow's own real claims, not ours** — we must not reuse their numbers on our site; the pattern (quantified trust) is only transferable with genuine data.
